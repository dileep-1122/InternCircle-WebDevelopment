LIVE WEATHER DASHBOARD

Project Description:
A responsive Live Weather Dashboard developed using HTML, CSS, and JavaScript. The application fetches real-time weather information for a selected city and displays the current temperature, weather conditions, weather icons, and a 5-day forecast.

Features:

- Search weather by city name
- Real-time weather data
- Current temperature and weather condition
- Weather icons
- 5-day weather forecast
- Dynamic content rendering using JavaScript
- Fetch API with async/await
- Search input validation
- Error handling for invalid cities
- Responsive design for mobile and desktop

Technologies Used:

- HTML5
- CSS3
- JavaScript
- Fetch API
- Open-Meteo Weather API

Project Files:

- index.html - Main webpage structure
- style.css - Website styling and responsive design
- script.js - Weather API, search, and forecast functionality
- README.txt - Project information

How to Run:

1. Open the project folder.
2. Open index.html in a web browser.
3. Enter a city name in the search box.
4. Click the Search button.
5. View the current weather and 5-day forecast.

Expected Outcome:
A beginner-friendly weather application demonstrating asynchronous JavaScript, Fetch API, async/await, DOM manipulation, API data handling, input validation, and responsive web design.
