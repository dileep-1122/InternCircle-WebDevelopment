MINI E-COMMERE-APP

Project Description:
A simple and responsive Mini E-Commerce App developed using HTML, CSS, and JavaScript. The application displays products dynamically and provides an interactive shopping cart.

Features:

- Dynamic product rendering using JavaScript objects
- Add products to shopping cart
- Increase and decrease product quantity
- Remove products from cart
- Automatic item count calculation
- Automatic total price calculation
- Shopping cart modal
- Checkout preview modal
- Order confirmation
- Responsive design for mobile and desktop

Technologies Used:

- HTML5
- CSS3
- JavaScript

Project Files:

- index.html - Main webpage
- style.css - Website styling and responsive design
- script.js - Product data, cart functionality, calculations, and modal handling
- README.txt - Project information

How to Run:

1. Download or clone the project.
2. Open the project folder.
3. Open index.html in a web browser.
4. Select products and click "Add to Cart".
5. Open the cart to view items and total price.
6. Click "Checkout" to view the checkout preview.

Expected Outcome:
A polished beginner-level e-commerce web application demonstrating JavaScript DOM manipulation, objects, arrays, event handling, cart management, and dynamic content rendering.
